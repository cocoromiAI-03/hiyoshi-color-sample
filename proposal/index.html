考え方（トップ）

もとのピンクが主役

ヘッダー・最初の画面・ボタン・番号・お問い合わせの帯など、ピンクの面は6月の色のまま残しました。ピンクの量は減らしていません。

ネイビーは「文字」と「締め」に

ピンクの上の白い文字をネイビーに変えました。白い文字より読みやすく（1.9 → 5.6 : 1）、甘さが抑えられます。お知らせの見出し・症状別ガイドの帯・フッターをネイビーにして、ページ全体を引き締めています。

ピンクは線とマーカーにも

見出しの文字はネイビーにして、下にもとのピンクの短い線を添えました。本文の強調はネイビーの文字＋うすいピンクのマーカー。英語の小見出しはブルーグレーです。

色の役割（トップ）

「読みやすさ」は文字と背景の色の差です。ウェブの読みやすさの国際的な目安（WCAG）では 4.5 以上が合格で、数字が大きいほど読みやすくなります。

発熱外来：派手すぎる赤を、少し落ち着いたトーンに

6月の色#E60012白い文字 4.8 : 1 → 新しい案#BF3F48白い文字 5.2 : 1

赤みと明るさはそのままに、鮮やかさだけを半分にしました。「発熱外来」と一目で分かる赤は残しつつ、目に刺さる強さを抑えています。濃い赤（文字用）も同じ考え方で #B4000E → #903139 にしました。

赤い予約ボタンは、6月の色でも暗い赤の文字で読みにくかった（2.9 : 1）ため、今回の赤に合わせて白い文字にしています（5.2 : 1）。

確かめたこと・注意

  • 発熱外来以外の6科のページは、「新しい案」と「6月の色」で全要素の色が同じです（機械で照合）。
  • トップは文字と背景の色の差をすべて測り、基準（4.5 : 1、大きな文字は 3 : 1）を満たしています。写真の上に白い文字をのせている見出しは、写真の明るさによるため対象外です。
  • 発熱外来のページで基準を下回るのは、6月の色のまま残した部分だけです（「受診前に確認したい記事」のピンクの文字、写真の上の白い見出し）。
  • スマホの幅（375px）でも、横にはみ出す部分はありません。スマホのメニュー（三本線のボタンと開いた画面）もネイビーの文字にしています。
  • 写真・画像の中の色（画像でできたボタンなど）と、LINE予約の緑（LINE の決まりの色）は変わりません。
  • この見本は、今のサイトの色を上から置き換えて作っています。本番に反映するときは、サイトのデザイン指定（CSS）の色を差し替える作業が別に必要です。
